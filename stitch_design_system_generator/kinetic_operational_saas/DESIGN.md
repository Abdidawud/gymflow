## Brand & Style

This design system delivers an operational, high-clarity dashboard environment engineered for high-throughput gym management and reception operations. Frontline staff operate under continuous time pressure; therefore, the aesthetic philosophy completely rejects decorative clutter, aggressive skeuomorphism, intense drop shadows, and transient visual novelties in favor of utilitarian, structured clarity.

### Personality & Tone
* **Utilitarian & Decisive:** Interfaces emphasize scan-efficiency, rapid keyboard workflows, and unambiguous status communication.
* **Grounded & Reliable:** Grounded in a deep, authoritative indigo core, neutral slates, and strict semantic roles.
* **Accessible & Tactile:** Generous minimum tap targets, WCAG AA compliant contrast ratios, and clean bounding lines make workflows effortless under varying ambient lighting.

### Visual Movement
The system balances modern SaaS minimalism with crisp, structured data density. High visual contrast between canvases and surfaces is reinforced through crisp 1px borders, subtle low-elevation ambient drop shadows, and persistent status-badge indicators.

## Colors

The color system delivers high legibility and unambiguous state signaling.

### Core Foundation
* **Primary Indigo (`#4338CA` / `#A5B4FC` in dark):** Used for focal interactive states, primary submit buttons, active navigation markers, and focus outlines.
* **Canvas & Surface Tier:** Light mode pairs a soft cool slate canvas (`#F8FAFC`) with pure white card surfaces (`#FFFFFF`). Dark mode transitions the background to `#0F172A` with elevated card containers at `#1E293B`.
* **Structural Borders:** Deliberate 1px divider outlines (`#E2E8F0` Light / `#475569` Dark) establish structural definition without needing elevation.

### Status Semantic System
Membership statuses rely on dedicated foreground-on-background combinations to guarantee accessibility:
* **Active (Success):** `#166534` text on `#DCFCE7` fill (Light) / `#BBF7D0` on `#14532D` (Dark).
* **Expiring Soon (Warning):** `#92400E` text on `#FEF3C7` fill (Light) / `#FDE68A` on `#78350F` (Dark) for renewals within 7 days.
* **Expired / Destructive (Danger):** `#991B1B` text on `#FEE2E2` fill (Light) / `#FECACA` on `#7F1D1D` (Dark). Pure red is strictly quarantined for expired entities, destructive actions, and critical errors.
* **Neutral / Scheduled:** `#334155` text on `#E2E8F0` fill (Light) / `#E2E8F0` on `#334155` (Dark).

### Print Surface Isolation
Print layouts (such as member payment receipts) ignore the dark theme token layer entirely, rendering with `#FFFFFF` paper surfaces and `#0F172A` text.

## Typography

The typography scale utilizes **Inter** across all display sizes, leveraging its robust x-height and optimized tabular digits for numerical data scanning.

### Hierarchy & Scale Rules
* **Metric Display (`28px` – `36px`):** Reserved for high-value operational metrics (e.g., active member counts, monthly recurring revenue totals). Always pairs bold weight with tabular numerals.
* **Page Headings (`26px` – `32px`):** Used strictly for high-level viewport titles and auth splash screens.
* **Section & Card Titles (`16px` – `20px`):** Applied to card headers, slide-over panel titles, and table headers.
* **Body Text (`14px` – `16px`):** `16px` serves as the primary reading body and form input field size; `14px` provides tight, scan-friendly density for data tables, secondary metadata, and description fields.
* **Status Badges & Captions (`12px`):** Semibold uppercase or title-case text rendered inside status pills and micro-metadata labels.

## Layout & Spacing

Layout geometry follows an exact **8px base spatial grid**, coupled with a **4px micro-increment** strictly designated for tight label/icon lockups.

### Shell Architecture
* **Desktop Sidebar:** Fixed width of `248px` positioned along the left edge, maintaining persistent global navigation on viewports `1024px` and wider.
* **Header Bar:** Persistent top navigation bar set to an exact height of `72px`.
* **Canvas Canvas Padding:** Content gutters adapt responsively, running `24px` (`1.5rem`) on tablet and mobile viewports, scaling to `32px` (`2rem`) on desktop.
* **Touch Targets:** All interactive triggers (buttons, search inputs, pagination links, dropdown triggers) enforce a strict minimum clickable boundary of `44px x 44px`.

### Responsive Breakpoints & Viewport Reflow
* **Desktop (`1024px+`):** Fixed 248px sidebar layout; multi-column metric card rows (3 to 4 columns); full data tables; right-aligned slide-out payment drawer (`420px` width overlay).
* **Tablet (`768px – 1023px`):** Sidebar collapses to an icon bar or mobile overlay drawer; metric cards wrap into a 2-column grid; tables switch to prioritized column visibility.
* **Mobile (`< 768px`):** Off-canvas navigation triggered by a top-bar hamburger toggle; stacked single-column metric cards; data tables convert to stacked card records; sliding payment drawers convert to full-screen modals.

## Elevation & Depth

This design system avoids multi-tier skeuomorphic drop shadows, deep blurs, and glassmorphism. It establishes structure and hierarchy using surface color contrast and crisp low-contrast bounding strokes.

### Elevation Hierarchy
* **Surface Tier 0 (Canvas):** Flat base page canvas (`#F8FAFC` light / `#0F172A` dark).
* **Surface Tier 1 (Cards, Tables, Panels):** Pure white cards with a `1px` continuous border in `#E2E8F0` (light) or `#475569` (dark). Enhanced with a subtle ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
* **Surface Tier 2 (Dropdowns & Popovers):** Positioned immediately above container surfaces using a refined boundary shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.05)`.
* **Surface Tier 3 (Drawers & Modals):** The desktop right-hand sliding payment drawer and confirmation dialogs utilize an elevation shadow of `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`. Modals pair with a dark semi-opaque backdrop scrim (`rgba(15, 23, 42, 0.5)`).

### Physical Print Override
The receipt view applies zero shadow and zero border, enforcing pure `#FFFFFF` background surfaces for crisp thermal and ink printing.

## Shapes

The design system uses a deliberate two-tier border-radius scale to balance compact input density with friendly, modern framing.

### Corner Radius Standards
* **Cards, Containers & Modals (`12px`):** All metric cards, data container panels, modal wrappers, and slide-out drawers use a continuous `12px` outer corner radius.
* **Interactive Elements (`8px`):** All input text fields, select dropdowns, search bars, action buttons, and segmented control containers use an `8px` corner radius.
* **Badges & Status Pills (`9999px`):** Membership status indicators, counter badges, and member tag chips utilize a full pill radius to visually distinguish them from rectangular action buttons.
* **Avatars (`9999px`):** Profile photos and dynamic initials fallbacks are circular.

## Components

### Buttons & Interactive Controls
* **Primary Button:** Background `#4338CA` (light) / `#A5B4FC` (dark), foreground text `#FFFFFF` (light) / `#0F172A` (dark). Sized with `12px` vertical padding, `16px` horizontal padding, minimum height of `44px`, and `8px` radius. Focus states apply a `2px` offset outline with `2px` indigo focus ring.
* **Secondary / Outline Button:** Background transparent, border `1px solid` `#E2E8F0` (light) / `#475569` (dark), text `#0F172A` (light) / `#F8FAFC` (dark).
* **Destructive Button:** Reserved for membership terminations and record deletions. Text `#991B1B` on `#FEE2E2` fill, or solid red fill for critical actions.

### Status Pills
* Fully rounded (`9999px`) badges with `4px` vertical padding and `10px` horizontal padding. Typography is Inter `12px` semibold.
* **Active Status:** `#166534` text on `#DCFCE7` background.
* **Expiring Soon Status:** `#92400E` text on `#FEF3C7` background (paired with label indicating remaining days).
* **Expired Status:** `#991B1B` text on `#FEE2E2` background.
* **Neutral / Scheduled:** `#334155` text on `#E2E8F0` background.
* Every status badge must include explicit descriptive text; icons or colored dots cannot be displayed without text.

### Form Inputs & Search Fields
* Container height minimum `44px`, `8px` radius, `1px solid` `#E2E8F0` border, `16px` body font.
* Focus state replaces the border with `#4338CA` and adds a subtle 1px ambient glow.
* Paired with `14px` semibold label positioned above the input with `6px` bottom spacing. Helper/error text sits `4px` beneath the input in `12px` caption styling.

### Cards & Panels
* Metric cards use `12px` border radius, `#FFFFFF` (light) / `#1E293B` (dark) background, `1px` `#E2E8F0` border, and `20px` to `24px` internal padding.
* Stat cards display the metric value in `32px` or `36px` bold with tabular digits, paired with a subtle subtitle indicating change period or total count.

### Tables & Data Lists
* Header row uses `#F8FAFC` background in light mode, `12px` semibold uppercase secondary text (`#475569`), with a bottom border in `#E2E8F0`.
* Cell data rows enforce `14px` body text, `16px` vertical cell padding, and horizontal row dividers. Hover states apply `#F1F5F9`.

### Drawers & Overlays
* **Payment Slide-Over Drawer:** Fixed `420px` width anchored to the desktop right edge; renders with a header containing member summary, itemized ETB currency breakdowns, and fixed action footer.
